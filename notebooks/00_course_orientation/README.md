# Chương 00 · Course Orientation — Giới thiệu khoá học & công cụ

> Tương ứng **Tuần 0** của khoá AIVN-Machine-Learning (Giới thiệu khoá học), được mở rộng thêm.

## 🎯 Mục tiêu

Sau chương này bạn sẽ:

- hiểu **triết lý** của khoá học (4 tầng USE → UNDERSTAND → ANALYZE → DESIGN) và cách một chương được tổ chức;
- biết cách làm **bài tập** (`### START CODE HERE ###`), **assignment** và **checkpoint** (gate PASS / REVIEW);
- cài đặt môi trường local (uv / conda / VS Code / PyCharm) **hoặc** dùng Google Colab (GPU miễn phí);
- thành thạo Jupyter Notebook, Markdown và LaTeX — "ngôn ngữ" của toàn bộ khoá học;
- có kỹ năng **tự học**: tìm kiếm, đọc tài liệu, đọc lỗi, đặt câu hỏi tốt.

## 📋 Yêu cầu trước

Không có. Đây là điểm bắt đầu.
