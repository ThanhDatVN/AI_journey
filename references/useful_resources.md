## Dữ liệu thật (khi làm capstone)

| Nguồn | Ghi chú |
|---|---|
| [UCI Machine Learning Repository](https://archive.ics.uci.edu) | bộ dữ liệu kinh điển, mô tả rõ |
| [Kaggle Datasets](https://www.kaggle.com/datasets) | đa dạng — kiểm tra giấy phép |
| [OpenML](https://www.openml.org) | dữ liệu kèm benchmark |
| [Hugging Face Datasets](https://huggingface.co/datasets) | văn bản (có tiếng Việt), ảnh, âm thanh |
| [Cổng dữ liệu quốc gia](https://data.gov.vn) | dữ liệu mở của Việt Nam |
| [Papers with Code](https://paperswithcode.com/datasets) | dữ liệu gắn với paper và kết quả |

Trước khi dùng dữ liệu thật: đọc giấy phép, kiểm tra dữ liệu cá nhân và quyền riêng tư, ghi nguồn và phiên bản (hash) trong README dự án (chương 39).
